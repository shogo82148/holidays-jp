holidays-jp API リファレンス

日本の祝日を返すシンプルな API です。認証不要、JSON で応答します。

ベース URL は https://holidays-jp.shogo82148.com です。 すべてのエンドポイントは GET リクエストを受け付け、 Content-Type: application/json の JSON を返します。

レスポンス形式

すべてのエンドポイントは、祝日の配列を holidays フィールドに格納したオブジェクトを返します。

{
  "holidays": [
    { "date": "2021-01-01", "name": "元日" }
  ]
}
フィールド型説明
holidaysarray祝日オブジェクトの配列。該当する祝日がない場合は空配列。
holidays[].datestring祝日の日付（YYYY-MM-DD 形式）。
holidays[].namestring祝日の名称（例: 元日）。

エンドポイント

1 年分の祝日を取得

GET/{year}

指定した年（YYYY）に含まれるすべての祝日を返します。

curl https://holidays-jp.shogo82148.com/2021

1 か月分の祝日を取得

GET/{year}/{month}

指定した年月（YYYY/MM）に含まれる祝日を返します。

curl https://holidays-jp.shogo82148.com/2021/01

特定の日が祝日かどうかを確認

GET/{year}/{month}/{day}

指定した日（YYYY/MM/DD）が祝日であれば、その祝日情報を返します。 祝日でない場合は holidays が空配列になります。 

curl https://holidays-jp.shogo82148.com/2021/01/01

期間を指定して祝日を取得

GET/holidays?from={YYYY-MM-DD}&to={YYYY-MM-DD}

from から to までの期間に含まれる祝日を返します。 from と to を省略した場合は、現在の年の祝日を返します。

クエリパラメータ説明
from期間の開始日（YYYY-MM-DD 形式）。
to期間の終了日（YYYY-MM-DD 形式）。
curl 'https://holidays-jp.shogo82148.com/holidays?from=2021-01-01&to=2021-01-31'
